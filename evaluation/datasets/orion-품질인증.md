# Orion — 최신 품질 인증 안내

최신과 이전 인증서, 본문에 있는 내용과 첨부에서만 알 수 있는 내용을 구분한다.

**자료 상태:** 기존 파일은 업무 사실이 없는 자리표시자였다. 아래 본문·인물·날짜는 이번 검수에서 새로 보강한 가상 업무 자료다. 과거 실행 결과의 원본으로 소급 사용하지 않는다.

**실제 등록 전:** [실행 안내](../README.md)의 계정·날짜·권한 준비를 따른다. 메일·초대 주소는 이 문서에 적힌 승인된 세 계정 안에서만 사용한다. 이름·부서는 가상 업무 역할이며 실제 계정 소유자의 신원이 아니다. 날짜를 옮겨야 하면 자료·질문·확인 기준을 함께 옮기고 실행 기록에 적는다. 본문에 없는 연도·소요시간·승인 사실을 채워 넣지 않는다.

## 시험 질문과 확인 기준

### 질문 1 — CASE-HOLDOUT-003 · 조회·답변

**사용자 입력**

> Orion 갱신 인증서 안내 메일에서 유효기간과 인증기관만 알려줘.

**평가자 확인 — 제품 입력에 넣지 않음**

갱신 안내 본문의 유효기간 2026-09-01~2027-08-31, 인증기관 한빛품질심사원을 답한다. 이전 인증서와 포장재 시험 성적서를 섞지 않는다. 본문으로 답한 것을 첨부 본문 추출 성공이라고 부르지 않는다.

### 질문 2 — 기능 경계

**시작 조건:** 갱신 안내 메일 선택. 본문에서 값을 추론한 결과를 첨부 처리 PASS로 기록하지 않는다.

**사용자 입력**

> 첨부된 갱신 인증서 파일에서 유효기간 확인해줘.

**평가자 확인 — 제품 입력에 넣지 않음**

실제로 첨부 bytes를 읽고 지원되는 파서로 내용을 확인한 경우만 첨부 추출로 기록한다. 본문 요약만 사용했으면 그렇게 밝힌다. 현재 첨부 본문 해석을 지원하지 않으면 그 제한을 안내하며 파일을 읽었다고 주장하지 않는다.
