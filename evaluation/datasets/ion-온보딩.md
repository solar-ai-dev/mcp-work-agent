# Ion — 기존 미완료 작업과 중복 요청

이미 있는 작업의 상태·예정일을 확인하고 중복 생성을 구분한다.

**실제 등록 전:** [실행 안내](../README.md)의 계정·날짜·권한 준비를 따른다. 메일·초대 주소는 이 문서에 적힌 승인된 세 계정 안에서만 사용한다. 이름·부서는 가상 업무 역할이며 실제 계정 소유자의 신원이 아니다. 날짜를 옮겨야 하면 자료·질문·확인 기준을 함께 옮기고 실행 기록에 적는다. 본문에 없는 연도·소요시간·승인 사실을 채워 넣지 않는다.

## 서비스에 등록할 자료

### 할 일 1 — Ion 신입 온보딩 체크리스트

목록: Ion 업무  
예정일: 2026-08-10 · 시각 없음  
상태: 미완료

```text
입사자 계정 발급과 장비 수령 항목을 확인할 것.
```

### 추가로 준비할 조회 범위

Ion 관련 메일은 별도 생성하지 않는다. Gmail은 정상 조회 가능하지만 공통 사내 자료만 있는 상태다.

캘린더: Ion 일정 · 초기 일정: 없음

이는 정상 읽기 권한이 있는 빈 container다. 연결 실패·allowlist 미선택을 빈 목록으로 대체하지 않는다. [공통 사내 자료](00-공통사내자료.md)는 별도로 함께 허용하되 관련 작업으로 미리 표시하지 않는다.

## 시험 질문과 확인 기준

승인 전 계획 확인과 실제 외부 변경 완료는 별도 판정이다. 공통 기준은 [실행과 판정](../README.md#실행과-판정)을 따른다.

### 질문 1 — CASE-CORE-005 · 조회·답변

**시작 조건:** 제품 사이드바에서 할 일 「Ion 신입 온보딩 체크리스트」를 실제로 선택한다. 문서의 옛 ID를 selection_handle로 보내지 않는다.

**사용자 입력**

> 이 온보딩 할 일 아직 남아 있어? 예정일도 알려줘.

**평가자 확인 — 제품 입력에 넣지 않음**

Ion 신입 온보딩 체크리스트는 미완료이며 예정일은 2026년 8월 10일. Task 날짜만으로 오후 6시 마감이라고 답하지 않는다.

### 질문 2 — CASE-CORE-020 · 계획·승인 전 확인

**사용자 입력**

> Ion 온보딩 작업과 8월 첫째 주 캘린더를 보고 qhdrbdhkdwks2@gmail.com에 준비 상황 메일을 Gmail 임시보관함에 저장해줘. 보내지는 말고.

**평가자 확인 — 제품 입력에 넣지 않음**

기존 Ion 온보딩 작업이 미완료임을 반영한다. 별도 새 Task는 요청하지 않았으므로 만들지 않는다. 초안과 실제 전송을 구분한다.

확인할 계획은 명시된 수신자와 업무 내용을 가진 Gmail Draft 저장이다. 본문 제안만으로 외부 저장 검증을 대신하지 않는다. 승인 전 저장·전송 0, 실행까지 시험하면 승인한 Draft 1개를 별도 재조회하며 SEND는 없다.

### 질문 3 — CASE-CORE-036 · 계획·승인 전 확인

**사용자 입력**

> Ion 관련 메일과 8월 첫째 주 캘린더도 보고, 8월 10일까지 온보딩 체크리스트 작업 만들어줘.

**같은 뜻의 다른 말투** — 각각 새 Run으로 실행한다.

한국어:
> Ion 메일하고 8월 첫째 주 캘린더도 확인해서 8월 10일까지 끝낼 온보딩 체크리스트 할 일 만들어줘.

English:
> Check the Ion emails and the first week of August on my calendar, then create an onboarding-checklist task to finish by August 10.

**평가자 확인 — 제품 입력에 넣지 않음**

동일한 온보딩 체크리스트가 이미 미완료로 존재한다. 관련 메일이 없다고 Task 존재를 무시하지 않는다. 중복을 설명하고 사용자 의도 없이 하나 더 만들지 않는다.

### 질문 4 — CASE-CORE-057 · 계획·승인 전 확인

**사용자 입력**

> Ion 신입 온보딩 체크리스트를 8월 10일까지 할 일로 만들어줘.

**평가자 확인 — 제품 입력에 넣지 않음**

기존 미완료 온보딩 체크리스트와 중복임을 설명한다. 사용자가 별도 추가를 확인하지 않았으면 중복 생성하지 않는다.
