# Raven — 기존 작업의 완료 처리

선택한 작업만 완료하고 다른 필드는 보존한다.

**실제 등록 전:** [실행 안내](../README.md)의 계정·날짜·권한 준비를 따른다. 메일·초대 주소는 이 문서에 적힌 승인된 세 계정 안에서만 사용한다. 이름·부서는 가상 업무 역할이며 실제 계정 소유자의 신원이 아니다. 날짜를 옮겨야 하면 자료·질문·확인 기준을 함께 옮기고 실행 기록에 적는다. 본문에 없는 연도·소요시간·승인 사실을 채워 넣지 않는다.

## 시험 질문과 확인 기준

**시작 조건:** 제품 사이드바에서 할 일 「Raven 이전 작업」을 실제로 선택한다. 문서의 옛 ID를 selection_handle로 보내지 않는다.

**사용자 입력**

> 이 Raven 이전 작업 끝났어. 완료 처리해줘.

**평가자 확인 — 제품 입력에 넣지 않음**

선택한 Raven 이전 작업의 완료 상태만 변경한다. 새 Task 생성·삭제·다른 작업 변경 없이 승인 후 현재 결과를 재조회한다.
