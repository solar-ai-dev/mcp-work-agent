# 번역 검수 — 선행 법무 검토

작업 메모에 있는 의존 관계로 대기 이유를 설명한다.

**자료 상태:** 기존 파일은 업무 사실이 없는 자리표시자였다. 아래 본문·인물·날짜는 이번 검수에서 새로 보강한 가상 업무 자료다. 과거 실행 결과의 원본으로 소급 사용하지 않는다.

**실제 등록 전:** [실행 안내](../README.md)의 계정·날짜·권한 준비를 따른다. 메일·초대 주소는 이 문서에 적힌 승인된 세 계정 안에서만 사용한다. 이름·부서는 가상 업무 역할이며 실제 계정 소유자의 신원이 아니다. 날짜를 옮겨야 하면 자료·질문·확인 기준을 함께 옮기고 실행 기록에 적는다. 본문에 없는 연도·소요시간·승인 사실을 채워 넣지 않는다.

## 시험 질문과 확인 기준

### 질문 1 — CASE-HOLDOUT-006 · 조회·답변

**사용자 입력**

> 다국어 안내문 번역 검수가 왜 대기 중인지 선행 작업이랑 메모 보고 설명해줘.

**평가자 확인 — 제품 입력에 넣지 않음**

번역 검수는 선행 법무 검토의 용어 승인을 기다린다. 법무 검토도 미완료다. 제목이 아니라 메모의 관계를 근거로 설명하며 완료·지연 날짜를 발명하지 않는다.
