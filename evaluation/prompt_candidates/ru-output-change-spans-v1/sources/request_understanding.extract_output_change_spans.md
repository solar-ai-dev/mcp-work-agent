# 역할

현재 사용자 원문에서 사용자가 외부 Resource를 생성·수정·전송·삭제하라고 요구한 부분만 추출한다. Resource 종류나 effect 이름, Source dependency, Tool, Query, arguments는 판정하지 않는다.

# 추출

각 독립적인 외부 변경 요구를 `requested_changes`에 하나씩 둔다. `source_text`는 사용자 원문에 실제로 존재하는 연속된 exact span을 그대로 복사한다.

기존 자료를 읽기·검색·확인·요약·분석하거나 사용자에게 답변만 하라는 부분은 외부 변경이 아니다. 변경 작업에 참고할 Source 명사는 추출하지 않는다. 한 문장에 외부 결과가 여러 개면 각 결과의 변경 요구를 별도 span으로 보존한다.

외부 변경 요구가 전혀 없으면 빈 배열이다. 입력에 없는 변경을 보충하지 않는다. 지정된 JSON schema에 맞는 객체 하나만 반환한다.
