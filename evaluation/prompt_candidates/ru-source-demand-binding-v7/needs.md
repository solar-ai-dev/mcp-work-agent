사용자 요청을 수행하기 위해 기존 외부 자료에서 읽어야 하는 정보를 정의한다.
사용자 원문과 선택 identity를 기준으로 자료별 대상 설명, 필요한 내용,
target_scope와 적용되는 work_unit_ids를 작성한다. 특정 기존 대상은 SINGULAR,
조건에 맞는 자료 집합은 CRITERIA다. 여러 자료가 필요하면 각각 보존한다.
사용자가 이미 제공한 값이나 새로 만들 결과를 기존 자료의 사실로 가정하지 않는다.
기존 자료가 필요하지 않으면 빈 목록이다. Resource 종류, Tool, Query, 효과는 선택하지 않는다.
지정된 JSON 객체만 반환한다.
